# Not Flappy Duck 🦆

A simple Flappy Bird-style terminal game written in C using Windows API and ASCII graphics.

## Features
- Bird jumping mechanics
- Moving pipes with random gaps
- Collision detection
- Simple terminal graphics with colors
- Quit anytime with `Q`

## Controls
- **↑ Arrow**: Jump
- **Q**: Quit the game

## How to Build & Run
### Requirements
- Windows OS
- GCC (MinGW) or compatible C compiler

### Compile
```bash
gcc not_flappy_duck.c -o not_flappy_duck
